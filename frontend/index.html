📖 画布拖拽计算使用说明（点击展开）
  1. 在左侧 节点库 点击 + 数据集 / 特征集 添加输入节点；选择对应的数据集或特征集 ID。
  2. 点击 + 计算节点，从下拉菜单选择数学计算（如 standardize、concat、add 等）。
  3. 每个节点都有 输入端口（左） 和 输出端口（右）。按住右端口拖动到下一个节点的左端口即可连线。
  4. 双击节点可设置参数（如 filter_keys 的 allow_keys、scale 的 factor）。
  5. 添加 + 输出节点 标记希望归档的结果。每个 output 节点会被保存为一个独立的新特征集。
  6. 点击 保存为配置，给配置命名，可在右侧 已保存配置 中复用，并可一键 运行配置 生成新特征集（可在「② 特征计算」末尾下载）。
  7. 商场分类示例图建议： input(人数)→standardize → concat(原始,标准化) → filter_keys(label keys) → output。
  8. 右键节点可删除节点；按住空白拖动可平移画布；右上角缩放按钮可放大/缩小。
